# Logo sources

All brand logos below are the companies' own official artwork, downloaded from the
public sources listed. They are used here only to show which payment methods the
shop accepts, which is the purpose each scheme publishes them for. Each brand's own
usage guidelines still apply — don't recolour, stretch or redraw them.

## Drawn icons (no brand artwork exists)

`cash.svg`, `wallet.svg`, `all-banks.svg` — generic icons in the site's palette,
generated by `tools/make-logos.py`.

## Swapping in a different logo

Drop the new file into this folder under the same name (or change the `src` in
`index.html`, and the `BANKS` array in the same file for the strip).
Nothing else needs to change — tiles use `object-fit: contain`.
